# 🏢 AI 오피스

AI 직원 6명이 귀여운 사무실에서 실제로 일하는 개인용 대시보드입니다.
비서에게 말하면 비서가 업무를 나누고, 직원들이 결과 파일을 만들어 보고합니다.

> GPT 직원이 오류로 멈추면(사용량 한도 등) 같은 일을 **Claude가 자동으로 이어받습니다.** 끄려면 `agents.local.json` 에 `{ "settings": { "fallback": {} } }`.

| 직원 | AI | 하는 일 |
|---|---|---|
| 비서 모찌 🐰 | Claude Code | 업무 나누기, 최종 보고 (팀 리더) |
| 기획자 곰곰 🐻 | Codex CLI (GPT) | 기획서, 구성안 |
| 리서처 킁킁 🐶 | Codex CLI (GPT) | 자료 조사 (출처 포함) |
| 개발자 냥코 🐱 | Codex CLI (GPT) | 웹페이지, 자동화 |
| 디자이너 햄찌 🐹 | Codex CLI (GPT 이미지 생성) | 썸네일, 이미지 |
| 마케터 삐약 🐥 | Codex CLI (GPT) | 후킹 문구, SNS 글 |

## 1. 처음 한 번만 준비하기

1. **Node.js 설치**: https://nodejs.org 에서 LTS 버전을 받아 설치합니다.
2. **AI 프로그램 설치·로그인**: 터미널에 한 줄씩 입력합니다.

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

```bash
npm install -g @openai/codex
```

3. 터미널을 껐다 켠 뒤 `claude` 와 `codex` 를 한 번씩 실행해서 로그인합니다.

> Claude는 Pro/Max 구독, Codex는 ChatGPT 유료 구독으로 쓸 수 있습니다.

## 2. 설치하기 (맥) — 한 줄이면 끝

터미널에 아래 한 줄을 붙여넣고 Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/nextkeybr/test-project/claude/ecstatic-lovelace-echyjs/ai-office/install-mac.sh | bash
```

- 내 컴퓨터의 `AI-Office` 폴더(홈 폴더 안)에 설치되고, **바탕화면에 `AI오피스` 아이콘**이 생깁니다.
- 앞으로는 **바탕화면 아이콘 더블클릭**으로 켜면 됩니다. 브라우저가 자동으로 열립니다.
- 끌 때는 뜬 터미널 창을 닫거나 Ctrl + C.

### 업데이트
새 버전이 나오면 사무실 화면 왼쪽 위에 **✨ 새 버전 업데이트** 버튼이 나타납니다. 누르면 자동으로 받고 다시 열립니다.
채팅 기록, 결과물, 캐릭터 이미지, 내 설정은 그대로 남습니다.

### AI 없이 먼저 구경하기 (연습 모드)
`AI-Office` 폴더에서 `npm run demo`. 가짜 직원들이 일하는 흐름을 보여줍니다. 비용이 들지 않습니다.

## 2-1. 설치하기 (윈도우) — 한 줄이면 끝

1. 먼저 준비: Node.js(https://nodejs.org), 그리고 PowerShell 에서 Claude Code 설치 `irm https://claude.ai/install.ps1 | iex` 와 `npm install -g @openai/codex` 후 각각 로그인.
2. 시작 버튼 → `powershell` 입력 → **Windows PowerShell** 을 열고 아래 한 줄을 붙여넣고 Enter:

```powershell
irm https://raw.githubusercontent.com/nextkeybr/test-project/claude/ecstatic-lovelace-echyjs/ai-office/install-win.ps1 | iex
```

- 내 사용자 폴더 안 `AI-Office` 에 설치되고, **바탕화면에 `AI오피스` 아이콘**이 생깁니다.
- 앞으로는 아이콘 더블클릭으로 켜고, 업데이트는 화면의 **✨ 새 버전 업데이트** 버튼으로 합니다.

## 3. 사용 방법

- **왼쪽 채팅창** → 비서에게 지시합니다. 예: `다음 주 올릴 고양이 쇼츠 3개 기획부터 썸네일, 제목까지 준비해줘`
- **특정 직원에게 바로**: `@마케터 이 제목 10개 버전 만들어줘`
- **아래 터미널 창** → 선택한 직원이 지금 무슨 일을 하는지 실시간으로 보입니다. 캐릭터를 클릭하면 바뀝니다.
- **결과물 탭** → 직원들이 만든 파일이 모입니다. 파일을 누르면 사무실 위에 크게 미리보기가 뜨고 ✕(또는 Esc)로 닫습니다. 실제 위치는 `shared/` 폴더입니다.
- **퇴근 버튼** → 그 직원은 새 업무를 받지 않습니다 (비용 절약).
- **작업 중지** → 지금 하던 일을 멈춥니다.

### 파일 첨부 (레퍼런스 이미지, 영상, 음악, 나레이션, 문서)
- 파일을 **채팅창이나 아래 작업 창으로 끌어다 놓으면** 바로 첨부됩니다. 여러 개를 한 번에 놓아도 됩니다.
- 📎 버튼 → **💻 내 컴퓨터에서 올리기** 로 골라도 됩니다.
- 첨부된 파일은 입력칸 위에 표시되고, × 로 뺄 수 있습니다. 지시를 적고 보내기를 누르면 파일과 함께 전달됩니다.
- 올린 파일은 `shared/uploads/날짜/` 에 자동 정리되고, 나중에 📎 로 다시 고를 수 있습니다.
- 올릴 수 있는 것: 이미지(png·jpg·webp·gif·heic 등), 영상(mp4·mov 등), 음악·나레이션(mp3·wav·m4a 등), 문서(md·txt·pdf·csv·srt·docx 등). 최대 2GB.
- 참고: AI 직원은 이미지와 글 문서는 직접 보고 읽을 수 있지만, 영상·음악은 직접 보거나 듣지 못합니다.
- **영상은 자동 분석**: 영상을 올리면 장면 모음표(전체 흐름 최대 24장), 첫 3초 장면(후킹 분석용 12장), 길이·화면 비율 정보를 만들어 직원에게 같이 넘깁니다. 이 기능은 **ffmpeg** 가 필요합니다.
  - 있는지 확인: 터미널(맥) / PowerShell(윈도우)에서 `ffmpeg -version` → 글자가 쭉 나오면 설치된 것
  - 없으면 설치: 맥 `brew install ffmpeg`, 윈도우 `winget install Gyan.FFmpeg` → 설치 후 사무실을 껐다 켜기 (윈도우는 PC를 다시 로그인해야 할 수도 있음)

### 어제 작업 이어서 하기
- "어제 작업 이어서 대본 써줘"처럼 **이어서·어제·지난번** 같은 말을 넣으면, 보내기 전에 **지난 결과물 고르는 창**이 자동으로 뜹니다.
- 결과물은 **어떤 요청으로 만든 작업인지** 묶여서 보이고, 여러 개를 체크할 수 있습니다. 묶음 제목을 체크하면 그 작업 파일이 전부 선택됩니다.
- 언제든 채팅칸 왼쪽 **📎 버튼**으로 직접 골라 붙일 수도 있습니다.
- 같은 이름 파일이 다른 날 또 만들어지면 지우지 않고 `plan-2.md` 처럼 이름을 바꿔 둘 다 남깁니다.

### 일이 흘러가는 순서
1. 비서가 요청을 읽고 먼저 할 일(예: 조사, 기획)을 나눕니다.
2. 직원들이 일을 끝내면 비서가 결과를 검토하고 다음 일(디자인, 문구, 개발)을 나눕니다.
3. 다 끝나면 비서가 최종 보고를 올립니다. (무한 반복 방지: 최대 4차례)

## 4. 내 캐릭터로 바꾸기

**가장 쉬운 방법:** 이미지 파일을 사무실 화면의 **캐릭터나 왼쪽 직원 목록 위로 끌어다 놓으면** 바로 바뀝니다.
아래 터미널 창의 **🖼 캐릭터 바꾸기** 버튼으로 파일을 골라도 되고, 원래 캐릭터로 되돌릴 수도 있습니다.
(끌어다 놓을 때 Shift를 누르고 있으면 "일할 때 모습"으로 들어갑니다)

직접 넣고 싶으면 `public/characters/` 폴더에 `secretary.png` 처럼 **직원 id 이름**으로 넣어도 됩니다.

- 배경 투명, 정사각형(512x512) 권장
- 일할 때 모습: `secretary-work.png` 처럼 `-work` 를 붙여 따로 넣기
- **사무실 배경 바꾸기**: 사무실 오른쪽 위 **🎨 배경** → "디자이너에게 새 배경 맡기기"를 누르면, 지금 사무실 모습과 캐릭터 이미지를 레퍼런스로 붙여 GPT 디자이너에게 맡깁니다. 완성된 이미지를 눌러 미리보기 → **🏠 사무실 배경으로 쓰기**. 배경은 벽·바닥만 바뀌고 책상·소파·캐릭터는 그 위에 그대로 올라갑니다 (3:2 비율). "기본 배경으로 되돌리기"도 있습니다.

> ⚠️ 치이카와 같은 기존 캐릭터 이미지는 **혼자 보는 용도로만** 쓰세요. 스크린샷·영상으로 공개하거나 배포하면 저작권 문제가 생길 수 있습니다. 이 폴더의 이미지는 git에 올라가지 않게 해두었습니다.

## 5. 직원 바꾸기 (업데이트해도 안 지워지는 방법)

- **이름**: 직원을 클릭한 뒤 아래 터미널 창 위쪽의 **✏️ 이름** 버튼 → 새 이름 입력 → Enter. 직군(디자이너 등)은 그대로, 뒤 이름만 바뀝니다. 바꾼 이름으로 `@이름` 호출도 됩니다.

- **성격·업무 규칙**: `agents/<직원id>/role.md` 를 복사해서 같은 폴더에 `role.local.md` 로 저장한 뒤 그 파일을 고칩니다.
- **이름·AI·캐릭터 모양**: `AI-Office` 폴더에 `agents.local.json` 을 만들고 바꿀 것만 적습니다. 예:

```json
{
  "agents": [
    { "id": "secretary", "nickname": "치이카와" },
    { "id": "marketer", "engine": "claude" }
  ]
}
```

- `engine` 은 `claude` / `codex` 중 하나, `character.type` 은 bunny, bear, cat, dog, hamster, chick 중 하나입니다.
- `agents.json`, `role.md` 를 직접 고치면 업데이트 때 덮어써집니다.

## 6. 디자이너에게 이미지 생성 도구 연결하기 (선택)

디자이너는 기본적으로 SVG·HTML 시안과 이미지 프롬프트를 만듭니다. 실제 이미지를 만들게 하려면:

1. `agents/designer` 폴더에서 Claude Code에 이미지 생성 MCP를 추가합니다 (`claude mcp add ...` — 방법은 각 서비스 문서 참고).
2. 그 폴더에서 `claude` 를 한 번 실행해 도구 사용을 승인합니다.
3. `agents.local.json` 에 도구 허용을 넣습니다. 예: `{ "agents": [ { "id": "designer", "allowTools": ["mcp__도구이름"] } ] }`

> 이 부분은 서비스마다 방법이 달라 직접 확인이 필요합니다.

## 7. 안전 수칙

- 이 서버는 **내 컴퓨터에서만** 열립니다 (localhost). 다른 기기나 다른 웹사이트에서 직원에게 지시할 수 없게 막아두었습니다.
- Claude 직원은 허용된 도구(파일 읽기·쓰기, 웹 검색, 일부 명령)만 쓸 수 있고, 나머지는 자동으로 건너뜁니다.
- 직원들은 자기 폴더(`agents/<id>/`) 안에서만 파일을 만들도록 되어 있습니다.
- 메일 발송, SNS 게시, 배포 같은 바깥으로 나가는 일은 하지 않고 보고만 하도록 역할 설명서에 적어두었습니다.
- 직원을 많이 동시에 돌리면 사용량 한도를 빨리 씁니다. `agents.local.json` 의 `settings.maxParallel`(동시에 일하는 인원, 기본 3)으로 조절하세요.

## 8. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "프로그램을 찾을 수 없습니다" | 1단계 설치를 다시 하고, 터미널을 껐다 켜세요 |
| 직원이 오류로 끝남 | 아래 터미널 창의 기록을 확인. 대부분 로그인이 풀린 경우입니다 (1단계 3번) |
| 옵션 오류 (unknown option 등) | AI 프로그램 버전마다 옵션이 다를 수 있습니다. 알려주시면 고쳐서 업데이트로 보내드립니다 |
| "이미 켜져 있어요" | 사무실이 이미 켜져 있는 상태입니다. 브라우저에서 http://localhost:3939 를 여세요 |
