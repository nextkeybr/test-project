# 수전 쿤하우젠 편 인포그래픽 (40_gfx)

HTML + GSAP로 장면을 만들고 Playwright로 한 프레임씩 캡처한 뒤 ffmpeg로 묶는다.

## 다시 뽑기
```bash
cd kuhnhausen/gfx_src
npm install                      # gsap, pretendard, 나눔손글씨 펜, us-atlas
node render.mjs B43 B44          # 클립 렌더(이미 있는 파일은 건너뜀)
node render.mjs B43 --check      # 검수 프레임만 (_qc 폴더)
```
- 고칠 때는 `clips/Bxx.js`의 `file` 이름 버전을 올린다(v1 → v2). 덮어쓰지 않는다.
- 풀프레임은 H.264 .mp4(CRF 14), 오버레이는 투명 ProRes 4444 .mov.
  오버레이마다 확인용 mp4(회색 바탕)가 `40_gfx/_preview`에 같이 생긴다.
- 길이 = 앞 핸들 0.5초 + 본 길이 + 끝 정지 꼬리 3초 + 뒤 핸들 0.5초 (핸들·꼬리는 첫/끝 프레임 정지).
- 나레이션(TTS)에 맞춰 바뀌는 등장 시각은 `timing.json`에 있다. 값만 고치고 해당 클립의 버전을 올려 다시 뽑는다.
  대상: B02, B03, B04, B31-a, B37, B38-a, B60(b1·b2·b3), B66(a·b), B76(d1·d2), B81, B82
- 이전 버전 출력은 `40_gfx/_old/`에 있다.

## 구조
- `templates/` 템플릿 T01~T12 (T05 고정 라벨은 `lib/kit.js`의 `K.label`)
- `clips/` 클립별 값과 타이밍. 파일 하나 = 출력 파일 하나
- `data/oregon.js` 오리건주·카운티 경계 (us-atlas 3.0.1, 미국 인구조사국 카토그래픽 경계에서 추출, `tools_make_oregon.cjs`)

## 지시문에 없어서 정한 것
- B37·B38-a: B31-a에서 신고자가 '이웃'으로 밝혀졌으므로 이름표를 '이웃'으로. 화면에 다 안 들어가서 앞의 두 줄은 빼고 뒤 세 줄부터 보임
- B80: 끝 프레임 = 검은 바탕 위 화이트 20%
- B67(법정 발언, 선택)은 RA-002 원음을 쓰기로 정해지지 않아 만들지 않음
- 오버레이는 지시문에 퇴장이 적힌 클립(B07, B33, B53, B82)만 퇴장. 나머지는 끝 정지 꼬리로 편집에서 처리
- 지도 경로(B43·B44)는 설명용 곡선이며 실제 도로 데이터가 아님

## 추가 지시문 v1 반영(2026-10-26)
- 모든 기존 클립을 끝 정지 꼬리를 붙여 다시 뽑으면서 버전을 하나씩 올림(v1 → v2, B04 v2 → v3)
- 꼬리 3초가 쓸모 있도록, 지시문에 없던 끝 퇴장은 뺌(B07, B33, B53, B82처럼 지시문에 퇴장이 적힌 것은 그대로)
- 분리: B15 → a·b, B24 → a·b, B60 → b1·b2·b3, B66 → a·b, B76 → d1·d2 (+ 온타리오 지도). 분리 전 파일은 더 만들지 않음
- B53 새 카드("마이크")는 B55에서 꽂히는 "마이크(남편)" 카드와 같은 자리에 놓음
- B19 비네팅은 화면 가장자리 전체 효과라 말자막 자리에도 옅게 걸림
- B76 지도의 경로는 설명용 곡선(대략 주간고속도로 84번 방향)
